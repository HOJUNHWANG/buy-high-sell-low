# 홈 뉴스의 무한 요약 대기 표시 수정

사용자가 로그인한 홈에서 대부분의 기사가 `Generating AI summary...`에 머문다고 보고했다.

원인은 홈 카드가 `ai_summary=null`을 생성 중으로 간주한 조건이었다. `headline_only`는 본문을 확보하지 못한 최종 상태이며 실제 대기 작업을 뜻하지 않는다. 기존 뉴스 피드/종목 상세 수정에 홈 카드가 빠져 있었던 문제다. 점검 당시 최신 20건 중 10건이 이 상태였고, 최근 수집 3회 모두 피드 오류/DB 저장 실패는 없었다.

홈 카드를 독립 컴포넌트로 옮기고 홈·뉴스 피드·종목 상세에 공통 요약 없음 안내와 원문 링크를 적용했다. 본문이 없는 기사에 생성 중/가입하면 요약을 볼 수 있다는 표시를 하지 않는다. 원문 발췌와 출처를 확인한 요약은 별도 표시한다. 미검증 기존 데이터는 요약 없음으로 처리하고, 실제 존재하는 요약의 접근 제한은 유지한다. 요약 API의 미확보 응답에서도 향후 생성을 약속하는 표현을 제거했다. 수집·AI 생성 규칙이나 운영 DB는 변경하지 않았다.

검증: TypeScript/TSX 테스트 183개(새 렌더링 회귀 5개), ESLint, 타입 검사, 프로덕션 빌드 통과. TSX 테스트도 실제 검색/실행되도록 테스트 설정을 수정했다. 임시 인증 신원으로 로그인한 홈 20개 카드(본문 없음 10개), 뉴스 피드, INTC 상세와 비로그인 모바일을 확인했다. 브라우저 예외/가로 넘침은 없었고 임시 신원 정리도 성공했다.

본문이나 원문 근거가 없는 기사에 요약을 발명하지 않는다. 해당 기사는 제목과 원문 링크를 제공한다. 이 수정은 장시간 대기처럼 보이던 잘못된 상태를 바로잡는 작업이다.
